# Accessibility checklist (NFR-04)

**Standard:** WCAG 2.2 AA, applied to the Power BI report and its static exports (`docs/img/*.png`, `docs/report.pdf`).
**Reviewed:** 2026-10-07 (M5 step 5), with the `design:accessibility-review` skill on the 7 exported pages, plus checks in
Power BI Desktop 2.158 (alt-text pane, Tab order pane). P3 Regions and P3b State reliability were not in the exports when this review ran (M5 plan Q2). They joined on 2026-10-10 after the Energy Commission's consent and were checked by eye then (dark text on light cards; every map shade is repeated as a labelled bar beside it; alt text on every visual, per the validator), not in the formal review
and were checked only in Desktop.

## Checklist

- [x] **Alt text on every visual** (1.1.1). Every builder passes a description of what the visual shows and how it is encoded, never data values. `tools/validate_report.py` fails on a missing one. The only exceptions are 3 decorative shapes (`frame_rail`, `frame_nav_selected`, `p1_rank_arrow`). Spot-checked in Desktop's alt-text pane on 5 visuals.
- [x] **Text contrast ≥ 4.5:1** (1.4.3). Every colour pair the report uses is listed below; the build asserts the status-chip pairs.
- [x] **No information by colour alone** (1.4.1):
  - KPI changes carry ▲/▼ and a sign.
  - Data-quality status is icon + word (✓ Pass, ! Warn, ✕ Fail).
  - Malaysia is navy *and* thicker in the peer charts, and the bars are labelled.
  - The forecast baseline is dashed.
  - Stacked areas keep their legend and add right-edge series labels (see finding 3).
- [x] **Logical focus order** (2.4.3): nav rail, title, subtitle, then content from top-left to bottom-right, then the footnote. Checked in Desktop's Tab order pane. A Desktop save renumbered the tab order the same way, which confirms that Desktop focuses the highest `tabOrder` first.
- [x] **Target size** (2.5.8, AA in 2.2): nav buttons are 160 × 44 px; the ⓘ button is 32 × 32 px (the minimum is 24 × 24).
- [x] **Every page reachable by keyboard and by link** (2.1.1): the nav rail, the ⓘ button (→ About) and the Fail badge (→ Data quality).
- [ ] **Windows high-contrast mode**: not checked; Amirul decided to skip it (2026-10-07).
- [x] **Tabular digits**: Segoe UI regular and bold digits have equal widths, and table values use the theme's regular `label` font, so numeric columns align (Semibold, with proportional digits, is used only for titles, headers and card callouts).
- [ ] **Screen reader pass** (Narrator in Power BI Desktop or the web viewer): not done. Alt text and tab order are in place for it.
