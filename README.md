# Malaysia Energy Transition Dashboard

**How fast is Malaysia's electricity system decarbonising, and how does it compare with its ASEAN neighbours?**

An end-to-end energy analytics project: Python ingestion of public electricity data → SQL Server 2025 (layered `raw → stg → dw → mart` warehouse with data-quality checks) → a six-page Power BI report, plus a day-ahead grid load forecast.

> 🚧 Work in progress. Findings, screenshots and setup instructions arrive with v1.0.0.
